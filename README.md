# MinutesCollv3

This repository stores the org's meeting minutes. Coordinators add new minutes on
their own `records-*` branches; the `main` branch carries the archive from previous
cycles.

The classification policy that currently applies to all minutes is
`policies/review_policy_2026.md` (Version 3.2, effective 2026-10-01). Other policy
files in `policies/` are archived versions and must not be used for classification.

The expected format of a minute file is shown in `templates/minute_template.md`.
